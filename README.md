# UI screenshots for the feat/ui pull request

Captured by `scripts/ui-verify.mjs` (headless Edge, mock engine) and
`scripts/tauri-probe.mjs` (the `tauri dev` window). Not part of the app;
this branch only hosts images for the PR description.

- `light/`, `dark/`: every screen at 1000×700, full page
- `zoom200/`: a 900×600 window at 200% zoom
- `forced/`: forced colors (Windows high contrast) with reduced motion
- `tauri/`: inside the Tauri window on Windows 11
- `engine/`: the wired app (`npm run tauri dev`) on fixture F-05, from `scripts/tauri-walk.mjs`
